# EZMig Documentation

`EZMig` is a lightweight, SQL-first database migration tool designed for simplicity and CI/CD.

## Quick links

- [Deployment](deployment.md)
- [Development](development.md)

## Core commands

```bash
ezmig validate
ezmig plan
ezmig apply
ezmig rollback
```

## Philosophy

- SQL is the source of truth
- Migrations are deterministic and auditable
- Tooling should be CI-friendly and explicit
